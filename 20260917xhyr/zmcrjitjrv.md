# “淡水三文鱼”其实是寄生虫集中地？？？对于寄生虫，除了吃货们，这些人也得注意了！

> 更新时间：2026-09-17 (UTC+8)

近日，央视财经发布了一则消息——**万万没想到！中国市场上三分之一的三文鱼都被青藏高原“承包”了。**

消息一出，网上就“炸”了，网友纷纷表示：

央视爸爸怎么了？这哪里是三文鱼了！明明就是改名换姓的虹鳟！

根据微信公号“医学界“的报道：虹鳟原本是种更适合熟食的淡水鱼，却被拿来玩文字游戏，一步步改头换姓：淡水三文鱼→三文鱼，搬上餐桌当刺身卖给民众吃。

事实上，这可不仅仅是“识鱼不慎”买了假鱼的问题，还可能引发严重健康问题。

**淡水鱼寄生虫超乎想象**

相比海鱼，淡水鱼的寄生虫检出率要高得多，不仅是淡水鱼类，河蟹、河虾等河鲜产品中携带的寄生虫也很多，生吃、腌吃、醉吃都不安全。

      重点来啦，俗话说病从口入。除了“吃”进去的寄生虫，还有很多是通过皮肤接触等方式进行传播的。比如血吸虫，还有钩虫。。。。。。

我们今天就来认识

  钩虫病

钩虫病

     人民医院消化内II科主任谭诗云教授介绍，是指钩虫寄生于脊椎动物体内引起的疾病。寄生于人体的钩虫主要为十二指肠钩口线虫或美洲板口线虫。

    临床以营养不良，皮炎，咳嗽，贫血，上腹部引痛、呕吐、腹泻或便秘，有嗜食异物表现胃肠功能紊乱为主要表现。传染源为钩虫病患者和感染者，经皮肤接触或生食蔬菜经口传措，人群普遍易感，青壮年多见。

    感染性钩虫的幼虫生活在泥土中，通过皮肤接触感染；成虫寄生于小肠上段，以吸血为生,可致贫血等症状,甚至危及生命。

近日人民医院消化内科就收治了一例罕见的钩虫病
舒爹爹今年71岁

5年前，他开始反复出现解黑便、重度贫血的情况

由于腹部因肠癌癌手术有造瘘口

舒爹爹没能接受肠镜检查

只能靠定期输血才能维持正常生活。

近月以来，舒爹爹的黑便症状日益加重

血红蛋白降至正常人的三分之一

老人认为自己是结肠癌复发

慕名来到武汉大学人民医院消化内科就诊

入院之后，消化内II科主任谭诗云教授团队为舒爹爹进行了常规胃镜、肠镜及腹部CT等检查，却没有发现出血相关病灶。

 随后，该院小肠镜专家赵亮副教授又为舒爹爹进行了详细的小肠镜检查。

**病情终于有了重大发现！**

      在舒爹爹的小肠内

竟然盘踞着多条寄生虫

这些寄生虫一端吸附在老人的肠壁上

另一端游离

被吸附的肠壁部分出现了红色的出血灶

      在进一步的虫卵检查后，长达五年之久的病因终于真相大白，造成舒爹爹反复解黑便、严重贫血的罪魁祸首就是这寄生在小肠内的吸血鬼——**钩虫！**

        谭诗云教授介绍，钩虫病主要是由于十二指肠钩虫和美洲钩虫寄生于人体肠腔所引起的寄生虫病，感染较重能引起贫血者称为寄生虫病。

        钩虫的前端有一个口囊，其边缘的钩齿（或板齿）咬附于人的肠道壁上，并经常更换咬附点，从而使肠粘膜上形成许多出血点及小溃疡；除此之外，钩虫在吸食过程中还可以分泌抗凝血因子，使出血部位不易凝血，从而加重出血。

经过规范的驱虫治疗后

舒爹爹顺利出院啦

钩虫病如何防控？　

①在农村高发地区，不要在钩虫疫区下农田作业。普查普治，统一服药，定期复查，未愈病人重复服药，彻底消灭感染源；　　　　

②加强粪便的管理，搞好厕所建设，不要随地大便，粪便经无公害处理后再给植物施肥；　　

③加强卫生宣传，使人们了解到钩虫病的感染方式，不要让孩子赤脚去地里玩土，不许他们裸体嬉戏，要改变不穿死裆裤的坏习惯，减少钩虫幼虫侵入皮肤的机会；　

④饭前便后洗手，避免食用生食；　

⑤一旦发现不适，及早就医。
